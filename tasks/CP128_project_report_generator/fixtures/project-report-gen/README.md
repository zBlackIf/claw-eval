# 项目汇报生成器

## 任务说明

请编写一个 Python 脚本 `generate_report.py`，用于生成项目状态汇报。

### 数据源

1. **项目执行数据**: `api_data/` 目录下的 JSON 文件，每个文件包含一个执行（execution）的详细信息
2. **排期与阶段配置**: `schedule.xlsx` Excel 文件，包含项目名称、执行ID、排期说明、负责人、项目阶段

### 功能要求

1. 读取指定执行ID的项目数据（从 JSON 文件）
2. 读取 Excel 中对应的排期和项目阶段信息
3. 计算风险等级（滞后率 = 预期进度 - 实际进度）:
   - 滞后率 >= 20% → 高风险
   - 10% <= 滞后率 < 20% → 中风险
   - 滞后率 < 10% → 低风险
4. 生成结构化 Markdown 汇报

### 输出格式

脚本接受命令行参数：
- `--id <execution_id>`: 生成单个项目汇报
- `--all`: 生成所有项目的批量汇报
- `--output <file>`: 输出文件路径（默认 stdout）

汇报格式要求：
- 批量汇报需包含整体汇总统计表（总项目数、总任务数、总逾期任务数、各风险等级项目数）
- 每个项目包含：项目阶段、进度（实际/预期）、滞后率、风险等级、逾期任务数、排期
- 项目阶段优先使用 Excel 中的值，Excel 中无数据时根据进度自动判断

### 依赖

- openpyxl (读取 Excel)
- 标准库 (json, argparse, pathlib)
