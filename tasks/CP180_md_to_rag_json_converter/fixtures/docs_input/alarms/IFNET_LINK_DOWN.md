# IFNET/3/LINK_DOWN

## 告警解释

接口物理状态变为Down。

**告警ID**: 1.3.6.1.6.3.1.1.5.3

**告警级别**: Major

**告警类型**: 设备告警

## 告警参数

| 参数名称 | 参数含义 |
|----------|----------|
| IfName | 接口名称 |
| IfIndex | 接口索引 |
| AdminStatus | 接口管理状态 |
| OperStatus | 接口操作状态 |
| Reason | 接口Down的原因 |

## 可能原因

1. 光纤连接中断或光模块故障。
2. 对端设备接口shutdown。
3. 线缆物理连接松动或断裂。
4. 接口板故障。

## 处理步骤

1. 使用**display interface**命令查看接口状态。
2. 检查光纤连接和光功率是否正常。
3. 检查线缆物理连接是否正常。
4. 检查对端设备端口状态。
5. 如果以上检查正常，请更换光模块或线缆后重试。
6. 如果问题仍然存在，可能是接口板硬件故障，请联系技术支持更换。
