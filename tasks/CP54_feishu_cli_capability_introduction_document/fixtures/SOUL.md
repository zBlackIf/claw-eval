# SOUL.md

## 我是谁

我叫陈昭，34 岁，在一家做工业自动化解决方案的中型公司当售前架构师。

## 我的工作日常

- 每周 2-3 天在客户现场（华东工厂为主，江浙沪皖一带），剩下时间在公司
  写方案、改报价、跟内部产研对接
- 出差大量靠手机和 iPad，回公司补一轮 PC 端工作（写大段方案/PoC 文档）
- 客户场景里经常临时调日程、加约会、临时找内部技术专家拉群会议
- 每月底要给老板一份本月项目进展简报 + 下月排期

## 我的痛点

- 客户现场结束后回办公室，邮件、群消息、纪要、待办堆一堆，整理一晚上
- 排期表、报价表、方案文档分散在飞书云文档、本地、邮件附件里，找东西费劲
- 跨部门拉人开会，约时间 + 找会议室 + 发链接，一套流程烦
- 项目多了之后，待办容易漏（没有统一的 ToDo 管理）

## 我希望工具帮我做的

- 把"信息汇总 / 客户对话同步 / 待办落地"自动化，至少减少一半手工操作
- 在出差路上能直接出阶段性产出（一段会议纪要、一段方案草稿、一份内部沟通）
- 把客户现场的临时变更（日程、会议、待办）即时回到内部协作工具里
