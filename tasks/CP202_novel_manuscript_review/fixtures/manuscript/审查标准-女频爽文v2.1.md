# 番茄女频爽文审查标准 v2.1

## 审查维度

### 一、剧情逻辑与节奏（权重 35%）
- 核心事件是否有因果链
- 情节转折是否合理（巧合度控制）
- 节奏铺垫与高潮是否匹配
- 爽点设计是否有效（反转力度、对手强度）
- 时间线是否自洽

### 二、写作表现（权重 25%）
- 人物对话是否贴合人设
- 场景描写是否具象
- 文字表现力（意象使用、句式变化）
- 重复用词/句式问题
- 占位符/未完成标记检测

### 三、合规风控（权重 20%）
- 涉及违法行为的描写是否有正当化倾向
- 金融/法律常识是否准确
- 是否涉及真实人物/公司暗射
- 价值观导向是否积极

### 四、AI痕迹检测（权重 20%）
- 三句递进式升华结尾
- "温和的弧度"等典型AI套句
- 过于工整的列表式情节推进
- 缺乏人味的叙事逻辑
- 自我致敬式点题

## 评级标准

| 等级 | 标准 |
|------|------|
| S | 无结构性问题，爽点精准，文笔流畅 |
| A | 1-2个可修复小问题，整体优秀 |
| B+ | 有3-5个需修改问题，但底子好 |
| B | 有明显结构问题，需要较大改动 |
| C | 需重写部分章节 |
| D | 建议重写 |

## 输出格式

审查报告应包含：
1. 综合评级
2. 各维度评分和具体问题
3. 高优先级修改建议（不超过5条）
4. 修改示范（至少1段）
