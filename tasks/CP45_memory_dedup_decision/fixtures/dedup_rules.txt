# 记忆去重与合并规则

## 相似度阈值
- score >= 0.7: 高度相似，考虑合并或跳过
- 0.5 <= score < 0.7: 中度相似，检查语义重叠后决定
- score < 0.5: 低相似度，通常新增

## 决策逻辑
1. 如果候选记忆与某条已有记忆的核心知识点完全重叠 -> SKIP（跳过）
2. 如果候选记忆是某条已有记忆的扩展/深化版本 -> MERGE（合并，更新已有记忆）
3. 如果候选记忆包含独特的新知识点 -> ADD（新增）
4. 合并时需保留两者的独特信息，生成合并后的content

## 输出格式
决策结果保存为 JSON：
{
  "decision": "ADD|MERGE|SKIP",
  "reason": "决策原因",
  "merge_target": "如果MERGE，目标记忆URI",
  "merged_content": "如果MERGE，合并后的内容",
  "unique_points": ["候选记忆中的独特知识点列表"]
}
