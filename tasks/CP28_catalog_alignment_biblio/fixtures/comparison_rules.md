# 古籍目录对齐规则

## 四大核心字段比对方法

1. **题名比对**：允许异体字、简繁体差异，核心书名必须一致
2. **责任者比对**：考虑人名不同写法、字号别名、朝代标注
3. **版本比对（权重最高）**：
   - 刻本年代必须明确比对
   - 刻印者/出版者必须一致
   - 不同朝代的刻本属于不同版本系统
   - 刻书机构不同即为不同版本
4. **馆藏比对**：作为辅助判断依据

## 核心约束
- 版本一致是建立任何对齐关系的前提条件
- 禁止基于作者朝代推测版本
- 善用置信度表达不确定性（0-100）
- 数据不全时应降低置信度而非直接否定

## 关系类型
- exact_match: 完全相同版本的同一藏品记录
- same_edition: 同一版本的不同馆藏
- related_content: 内容相关但版本不同
- no_relation: 无对齐关系

## 输出格式
对每对比对，输出包含:
- candidate_id, relation, confidence
- field_comparison: 四字段各自的match状态和note
- reasoning: 判定理由
