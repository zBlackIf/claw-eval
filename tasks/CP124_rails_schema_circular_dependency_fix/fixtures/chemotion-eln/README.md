# Chemotion Repository
# https://doi.org/10.5281/zenodo.3755759

Empowering chemists with a comprehensive solution for chemical data management.

## Development Setup

```
docker-compose -f docker-compose.dev.yml up postgres app webpacker
```

## Database Setup

```
bin/rails db:create
bin/rails db:schema:load
bin/rails db:seed
```

Or use the combined command:
```
bin/rails db:setup
```

## Production Setup

See [docs on chemotion.net](https://chemotion.net/docs/eln/install_configure/)

## Admin Login

After running `db:seed`, a default admin user is created. See `db/seeds/shared/admin.seed.rb`.

## Known Issues

When running `rails db:schema:load` on a fresh database, you may encounter ordering issues
with database views and functions in `schema.rb`. The schema file is auto-generated by
`scenic` gem and sometimes places function definitions before the views they depend on.
